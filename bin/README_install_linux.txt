 PSeInt - Versión UTN-FRM-AyED (Portable para GNU/Linux x64)
 Cátedra de Algoritmos y Estructuras de Datos
 Facultad Regional Mendoza - Universidad Tecnológica Nacional
====================================================================

Esta versión de PSeInt está configurada y adaptada para la cátedra de
Algoritmos y Estructuras de Datos de la UTN Facultad Regional Mendoza.
Incluye el perfil personalizado UTN-FRM-AyED preconfigurado y la suite
de ejemplos de cátedra traducidos y verificados.

INSTRUCCIONES DE USO:
---------------------
1. Esta versión es portable: no requiere instalación en el sistema.
2. Descomprima el archivo tar.gz en la carpeta que desee:
      tar -xzf pseint-utn-frm-ayed-linux-x64.tar.gz
3. Ingrese a la carpeta descomprimida:
      cd pseint-linux
4. Para ejecutar el entorno gráfico principal, ejecute:
      ./wxPSeInt
   (o ./pseint)
5. Si lo desea, puede crear un acceso directo en su escritorio a este ejecutable.

EJECUTABLES INCLUIDOS:
----------------------
- wxPSeInt / pseint         : Lanzadores del entorno de desarrollo gráfico principal.
- bin/bin/pseint            : Intérprete y verificador en línea de comandos.
- bin/bin/wxPSeInt          : Binario de la interfaz gráfica.
- bin/bin/psdraw3 / psdrawE : Editor y exportador gráfico de diagramas de flujo.
- bin/bin/psterm            : Terminal de ejecución integrada.
- bin/bin/psexport          : Exportador a otros lenguajes (C, C++, Python, etc.).
