Ejemplos de Algoritmos - Cátedra UTN-FRM-AyED

    PSeInt incluye un conjunto de algoritmos ordenados por nivel de dificultad para ejemplificar la sintaxis y el uso del pseudocódigo de la cátedra. A continuación se describen los ejemplos disponibles:
  • 001_Suma: Este es el ejemplo más simple. Muestra cómo cargar dos números en variables, calcular la suma de los mismos y mostrarla en pantalla.
  • 001_Modulo: Ejemplo del uso del operador de módulo (MOD o %).
  • 002_Raices: Utiliza la fórmula resolvente para determinar las raíces de una ecuación cuadrática a partir de sus tres coeficientes.
  • 002_Romanos: Muestra cómo convertir números enteros a notación romana utilizando arreglos.
  • 002_Triangulo: Determina si tres lados corresponden a un triángulo rectángulo mediante Pitágoras e informa su área.
  • 003_AdivinaNumero: Juego en el que el usuario debe adivinar un número aleatorio generado por la computadora.
  • 003_Coloquial: Ejemplo con variantes de pseudocódigo coloquial.
  • 003_Digitos: Separa e imprime los dígitos de un número entero utilizando el operador módulo.
  • 003_Factorizacion: Algoritmo para descomponer un número en sus factores primos.
  • 003_Menu: Ejemplo de menú de opciones utilizando estructuras de control condicionales y repetitivas.
  • 003_Primos: Calcula iterativamente los N primeros números primos.
  • 003_Promedio: Cálculo de promedio utilizando un acumulador y bucle PARA / VARIAR.
  • 003_TaTeTi: Implementación del juego Ta-Te-Ti en pseudocódigo.
  • 005_Mayor_Arreglos: Búsqueda de los valores mayores dentro de una lista de datos en un arreglo.
  • 005_OrdenaLista: Almacena una lista de elementos en un arreglo y los ordena.
  • 005_RecorrerArreglo: Recorrido de un arreglo unidimensional utilizando bucles.
  • 005_Sucursales: Manejo de arreglos para registrar precios y cantidades vendidas en diferentes sucursales.
  • 006_Potencia_recursivo: Ejemplo de función recursiva para el cálculo de una potencia.
  • 006_Promedio: Uso de subprogramas y funciones pasando arreglos como parámetros.
  • 006_Subprogramas: Sintaxis para la definición e invocación de subprogramas (procedimientos y funciones).


Nota: la sintaxis de estos ejemplos está adaptada al perfil de la cátedra UTN-FRM-AyED.
